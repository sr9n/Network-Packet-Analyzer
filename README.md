# 📡 SR9N Network Packet Sniffer
**A high-performance network analysis tool built for security auditing and traffic monitoring.**

---

## 🚀 Overview
The **SR9N Sniffer** is a professional-grade Python tool designed to intercept and analyze network traffic in real-time. It provides deep insights into packet headers, protocols (TCP/UDP/ICMP), and data payloads, making it an essential tool for cybersecurity enthusiasts and network administrators.

## ✨ Key Features
* **Real-time Capture:** Intercepts live traffic from any network interface.
* **Protocol Identification:** Automatically detects and categorizes IP, TCP, UDP, and ICMP layers.
* **Payload Inspection:** Extracts raw data for deep analysis of network communication.
* **Clean Interface:** Uses a structured command-line output for better readability.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Core Library:** [Scapy](https://scapy.net/) (Powerful packet manipulation)
* **OS Support:** Windows / Linux
